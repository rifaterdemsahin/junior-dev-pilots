01 URL Anatomy — Parameter by Parameter

http://localhost:3002
Local HyperFrames Preview Server

Runs locally on your Mac via hyperframes@0.9.66 preview --background. It serves the Studio web UI, watches your project files for changes, compiles Google Fonts deterministically, and streams local WAV/MP3 assets.

#project/Junior%20Developers%20Become%20Delivery%20Pilots
Active Project Workspace

Client-side hash route pointing Studio to your folder ~/.hyperframes-studio/Junior Developers Become Delivery Pilots (URL-encoded spaces become %20).

comp=compositions%2Fshort-rider-driver-pilot.html
Target Composition File

Tells Studio to load your standalone portrait short (compositions/short-rider-driver-pilot.html) onto the stage instead of the default root index.html.

t=0
Playhead Timestamp (Seconds)

Seeks the registered GSAP timeline (window.__timelines["short-rider-driver-pilot"]) directly to 0.0s. Changing t= lets you deep-link to any exact frame (e.g. t=27.5 or t=42.5).

tab=variables
Inspector Panel Tab

Opens the Variables tab in the Studio sidebar so you can inspect and tweak live composition variables/properties without digging into raw HTML.

v=1 & rc=0
State Schema & Reload Counter

v=1 marks Studio URL state version 1. rc=0 tracks reload/revision cache state (0 = initial clean load; increments when Studio forces a fresh stage reload).

03 Managing the Local Server (CLI Commands)

Check if the background preview server is running npx --yes hyperframes@0.9.66 preview --status
Start (or restart) persistent Studio preview in background npx --yes hyperframes@0.9.66 preview --background
Stop the background preview server cleanly npx --yes hyperframes@0.9.66 preview --stop
Hand off to the HyperFrames Desktop App (auto-stops web preview) npx --yes hyperframes@0.9.66 open .
Re-render the standalone portrait short to high-quality MP4 npx --yes hyperframes@0.9.66 render -c compositions/short-rider-driver-pilot.html -q delivery -o renders/short-rider-driver-pilot.mp4
Note on Desktop App vs. Browser Studio: The HyperFrames desktop app cannot edit the project while the background preview server on localhost:3002 is running. Running npx --yes hyperframes@0.9.66 open . stops the background preview automatically before opening the desktop app.
